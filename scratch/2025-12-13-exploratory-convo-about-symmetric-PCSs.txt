  3. So transposing the input is equivalent to transposing the mask in the opposite direction.

> wait and what exactly is "overlap"? 

● Good question - I should be precise.

  Overlap = intersection = inter in our code

  It's the notes that are in both the mask and the input PCS.

  When you XOR:
  - Notes in overlap (mask ∩ input): get removed (1 + 1 = 0 in Z₂)
  - Notes in mask only (mask \ input): get added (0 + 1 = 1)
  - Notes in input only (input \ mask): stay (1 + 0 = 1)
  - Notes in neither: stay (0 + 0 = 0)

  So:
  added   = |mask| - |overlap|
  removed = |overlap|
  Δ       = added - removed = |mask| - 2*|overlap|

  The intersection is the "collision" between mask and input - those notes cancel out (get removed), while the non-overlapping mask notes get added.
