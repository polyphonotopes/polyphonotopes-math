  Polyphonotopes 2025

  A Rust project for visualizing musical scale relationships as interactive
  force-directed graphs.

  Structure

  polyphonotopes-2025/
  ├── polyphonotopes-rs/      # Core library - scale theory & graph
  algorithms
  ├── musical-graphs-app/     # Bevy visualization app
  └── cobwebs/                # Local physics/force simulation dep

  Key Tech Stack

  - Bevy 0.16.2 - rendering/ECS
  - fdg + cobwebs - force-directed graph layout
  - midir/midly - MIDI input
  - nih_plug + baseview - audio plugin support (VST3/CLAP)
  - bevy-jf-blur - visual focus effects

  Core Concepts

  - Scales represented as 12-bit bitsets (each bit = pitch class)
  - Graph nodes are scales, edges connect "related" scales (Hamming
  distance, etc.)
  - Force simulation positions nodes in 2D/3D space
  - MIDI input highlights active scales in real-time

> so what I'm interested in is expanding on this bitset representation and

● That's a beautiful framing. So you're viewing:

  - Objects: Pitch class sets (12-bit vectors over Z₂)
  - Morphisms: XOR-masks as transformations
  - Composition: XOR of masks (since (a xor b) xor c = a xor (b xor c))

  The key insight is that (Z₂^12, ⊕) acts on itself - every PCS is both a
  state and a transformation. This is the regular representation.

  And the monoidal structure captures that these transformations can be:
  - Composed sequentially: mask₁ ⊕ mask₂
  - Tensored in parallel (if we think about operating on multiple
  voices/parts)

● That's a nice insight. Starting from F=0 makes the structure cleaner:

  - Diatonic (F Lydian): {0, 2, 4, 6, 7, 9, 11} = {F, G, A, B, C, D, E}
  - Whole-tone: {0, 2, 4, 6, 8, 10} = even pitch classes
  - Chromatic complement of diatonic: {1, 3, 5, 8, 10} = the black keys

  The diatonic differs from whole-tone by just swapping {8, 10} for {7, 9,
  11} - a kind of "deformation" of the symmetric structure.

  Also, the circle of fifths starting from F gives you the diatonic notes in
   Lydian order before hitting any sharps/flats:
  F → C → G → D → A → E → B  (all naturals)
    → F# (first sharp)

  This makes F a more "natural" origin than C in some sense - C major just
  happens to have the white keys, but F Lydian is the "generator" of the
  diatonic system via fifths.

  Want to formalize the circle of fifths relationship? We could define:
  def fifth : PitchClass := 7
  def circleFifths (n : ℕ) : PitchClass := n * fifth

  And prove things about how the diatonic scale emerges from 7 consecutive
  fifths.
